## Description

The v0.5.0 package smoke test contains fixed expectations for selected package
metadata and allowlisted paths. Improve the test and package-release checks to
derive stable expectations from the package manifest where practical, while
keeping explicit assertions for the supported release contract.

This is a maintenance improvement only. It is not a prerequisite for the
v0.5.0 release.
