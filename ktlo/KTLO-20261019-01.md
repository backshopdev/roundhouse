## Description

`scripts/test-commit.js`'s npm-mode-a test sends arguments through the shell
with `cwd: repoRoot` (test-commit.js:122). For the multi-line-body case,
cmd.exe splits the newline-containing argv and the `--dry-run`/
`--dry-run-output` flags are lost — so `scripts/commit.js` performs a REAL
commit in the REAL repo. Demonstrated 2026-10-19: the Phase 4 gate flow's
test-commit run consumed the entire staged Phase 4 changeset into
unauthorized commit 7f26922 (remediated by human-ruled amend). Any future
run with a non-empty index can commit it without approval.

## Trigger

The Phase 4 gate flow's `scripts/test-commit.js` run (2026-10-19): the
npm-mode-a `long-body-with-footers` check lost its `--dry-run` flags to the
shell's newline splitting and committed the real repo's staged changeset.

## Evidence

- Commit 7f26922 — the unauthorized commit: mangled message
  ("docs(x): long body — em-dash" / "Body line one — em-dash → arrow."),
  correct content (the 10-file Phase 4 changeset); remediated by the
  human-ruled amend.
- `scripts/test-commit.js:122` — the npm-mode-a invocation runs
  `npm run commit` with `cwd: repoRoot` (the real repo; the temp dir holds
  only dry-run output files).
- The suite result 33/34 — `npm-mode-a long-body-with-footers` failing
  (first run: ENOENT reading the never-written dry-run output; second run:
  exit 1, "nothing added to commit" after the index was consumed).
- The suite's own header (test-commit.js:26-39) documents the transport
  defect class: "a FAIL is evidence of transport truncation/mangling."

## What was tried

N/A — the hazard is structural (the transport defect the suite exists to
demonstrate defeats its own dry-run protection).

## Why this matters now

Any future `test-commit.js` run with a non-empty index performs an
unauthorized commit; the harness's approval gates are bypassed by the
shell-splitting defect.

## Resolution criteria

The npm-mode-a hazard is closed — either the test runs in a sandbox clone,
the dry-run flags are reordered ahead of the body argument, or the
inline-multi-line npm-mode-a case is dropped; verified by a test-commit.js
run with a non-empty index performing no real commit.

## Impact

- Severity: High
- Affected systems: `scripts/test-commit.js`, the commit approval gates.

## Recurrence

- Frequency: Every `test-commit.js` run until fixed.
- Estimated effort: One focused harness change (sandbox clone, flag
  reorder, or case drop) plus one verification run.

## Procedure

1. Choose the fix (sandbox clone / flag reorder / case drop).
2. Implement.
3. Verify with a non-empty-index run.
4. Close.
