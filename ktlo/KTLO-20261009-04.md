# KTLO-20261009-04: `src/AGENTS.md` and `src/AGENTIC_WORKFLOW.md` sync script references

Last modified: 2026-10-09
Status: Active

## Description

<!-- Describe the operational maintenance task, known issue, or recurring
work. -->

Root `AGENTS.md` and `AGENTIC_WORKFLOW.md` reference the
`npm run sync-roundhouse` command and the `scripts/sync-roundhouse.js`
script, but the corresponding `src/` template files do not reference the
sync script by name at all. The root and template copies therefore
disagree about whether and how the sync script is described to consumers.
This is a pre-existing inconsistency between root and template.

## Impact

<!-- What happens if this item is not addressed? -->

- Severity: Low
- Affected systems: Root `AGENTS.md`; root `AGENTIC_WORKFLOW.md`;
  `src/AGENTS.md`; `src/AGENTIC_WORKFLOW.md`; any consumer that seeds
  from the template.

Template consumers may not know about the sync script, or may receive
contradictory instructions depending on which copy they read first. The
divergence also increases the risk that future edits are made in only
one location.

## Recurrence

<!-- How often does this work need to be done? -->

- Frequency: As needed
- Estimated effort: A small edit to both `src/` template files (and a
  sync to root via `npm run sync-roundhouse` if a root update is also
  required).

## Procedure

<!-- Step-by-step instructions for performing this work. -->

1. Compare the root `AGENTS.md` and `AGENTIC_WORKFLOW.md` against the
   `src/` copies and identify the exact sentences that reference
   `npm run sync-roundhouse` or `scripts/sync-roundhouse.js` in root
   but not in `src/`.
2. Decide on the canonical wording (likely a single source of truth in
   `src/` that mirrors the root intent).
3. Edit `src/AGENTS.md` and `src/AGENTIC_WORKFLOW.md` to add the
   missing references.
4. Run `npm run sync-roundhouse` to propagate the change to root, then
   run `npm run test-sync` to confirm no drift.
5. Run `node .opencode/docs-check.js` and `npx --yes
   markdownlint-cli2@0.23.2` to confirm no documentation regressions.
