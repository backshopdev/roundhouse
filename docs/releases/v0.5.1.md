# Release v0.5.1

## Summary

Patch release covering internal tooling fixes, documentation
standardization, and test isolation. No new features or breaking
changes for consumers.

## Changes since v0.5.0

- **`docs`**: standardized `index.md` structure across all 17 index
  files using three codified patterns (populated tables, bullet
  lists, section navigation).
- **`fix(sync)`**: added Mode 2 (create-if-missing) to
  `scripts/sync-roundhouse.js` so seed files (BUILDING.md, TESTING.md,
  etc.) sync from `src/` to root.
- **`test(sync)`**: refactored test suite to use an `os.tmpdir()`
  fixture instead of the real repo root; added Tests 15 and 16 to
  exercise the consumer-side `init` and `update` scenarios.
- **`chore`**: bumped Node engines pin to `>= 22.0.0`.

## For consumers

No consumer-facing changes. Consumers can upgrade freely.
Node 22.0.0 is now the minimum supported runtime.

## For contributors

Internal workflow tooling only. The architecture now treats
`src/` as canonical and root as the deployed instance; the
sync script enforces this invariant automatically.
